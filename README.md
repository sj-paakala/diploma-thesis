# Master's Thesis Repository

This repository is intended to support the management and versioning of my master's thesis project.

## Purpose

The repository keeps track of:
- the current thesis draft and related documents
- meeting notes with my supervisor
- progress and revision history
- outstanding tasks and next actions
- key decisions and feedback received

## Workflow

1. Keep the main thesis document in the project root or in a dedicated `thesis/` folder.
2. Record major updates in `CHANGELOG.md`.
3. Track outstanding work in `TODO.md`.
4. Save supervisor meetings in `meetings/` using the provided template.
5. Use commit messages to document important milestones and revisions.

## Suggested Structure

```text
.
├── README.md
├── CHANGELOG.md
├── TODO.md
├── meetings/
│   ├── MEETING_TEMPLATE.md
│   └── 2026-10-21_supervisor_meeting.md
├── thesis/
│   └── drafts/
├── references/
├── appendices/
├── figures/
└── notes/
```

## Notes

- Keep entries concise and factual.
- Use dates in the format `YYYY-MM-DD` for consistency.
- For each meeting, note: agenda, action items, decisions, and follow-up tasks.
